# 🎉 Smart Event Management System

A desktop-based Event Management System developed using **Java** and **JavaFX**. The application allows users to create events, register participants, filter events by date, and store event information permanently using Java Serialization.

This project demonstrates Object-Oriented Programming (OOP), JavaFX GUI development, exception handling, collections, file handling, and data persistence.

---

## ✨ Features

### 📅 Event Management
- Create new events
- Select event date
- Set participant capacity
- Assign event organizer

### 👥 Participant Registration
- Register participants
- Prevent duplicate registrations
- Prevent registrations when an event reaches capacity

### 🔍 Event Filtering
- Filter events by date
- Display matching events instantly

### 💾 Data Persistence
- Automatically saves events
- Loads saved events when the application starts
- Uses Java Serialization (`events.dat`)

### ⚠️ Exception Handling
Custom exceptions include:
- EventFullException
- DuplicateParticipantException
- EventNotFoundException

# ▶️ How to Run

1. Clone the repository

```
git clone https://github.com/your-username/Smart-Event-Management-System.git
```

2. Open the project in Eclipse or IntelliJ IDEA.

3. Configure JavaFX SDK.

4. Add VM Arguments:

```
--module-path "PATH_TO_JAVAFX/lib" --add-modules javafx.controls,javafx.fxml
```

5. Run the project.
